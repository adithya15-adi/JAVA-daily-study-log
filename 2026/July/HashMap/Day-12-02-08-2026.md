### 2. Frequency Counter

Counted the occurrence of every element in an array using a dictionary.

Example:

```python
a = [10,10,20,20,10,30,40,10,10,10,20,40,50,60,70,10,10,10]
```

Output

```python
{
10: 8,
20: 3,
30: 1,
40: 2,
50: 1,
60: 1,
70: 1
}
```

---

## 📋 Algorithm

### Frequency Counting

1. Create an empty dictionary.
2. Traverse the array.
3. If the element already exists:
   - Increment its count.
4. Otherwise:
   - Insert the element with count `1`.
5. Print the dictionary.

## 💡 Key Learnings

- A dictionary stores data as **key-value pairs**.
- Keys are unique.
- Values can be duplicated.
- Dictionaries provide **average O(1)** lookup and insertion.
- Frequency counting is one of the most common applications of dictionaries in DSA.
- Dictionaries help optimize many brute-force solutions.
