# 📋 Pattern Formula Cheat Sheet

## Basic Patterns

| Pattern | Formula |
|---------|---------|
| Solid Rectangle | `j <= n` |
| Half Pyramid | `j <= i` |
| Pyramid | `2*i - 1` |
| Inverted Half Pyramid | `n - i + 1` |
| Inverted Pyramid | `2*(n - i) + 1` |

---

## Advanced Patterns

| Pattern | Spaces | Stars |
|---------|--------|--------|
| Right Half Pyramid | `n - i` | `i` |
| Inverted Right Half Pyramid | `i - 1` | `n - i + 1` |
| Full Pyramid | `n - i` | `2*i - 1` |
| Inverted Full Pyramid | `i - 1` | `2*(n - i) + 1` |
| Diamond | Full Pyramid + Inverted Full Pyramid |

---

## Number Patterns

| Pattern | Formula |
|---------|---------|
| Same Number | `x = i` |
| Increasing Numbers | `x = 1`, `x++` |
| Reverse Numbers | `x = n`, `x--` |
| Floyd's Triangle | `x = 1`, don't reset |
| Reverse Floyd | `x = n(n+1)/2`, `x--` |
| Palindrome Pyramid | `1 → i → 1` |
| Descending Pyramid | `i → 1 → 2 → i` |
| Concentric Pattern | Left + Middle + Right + Mirror |

---

## Matrix Pattern Conditions

| Pattern | Condition |
|----------|-----------|
| Boundary | `i==1 || i==n || j==1 || j==n` |
| Main Diagonal | `i==j` |
| Secondary Diagonal | `i+j==n+1` |
| X Pattern | `i==j || i+j==n+1` |
| Boundary + X | Boundary + Both Diagonals |
| Top Boundary | `i==1` |
| Bottom Boundary | `i==n` |
| Left Boundary | `j==1` |
| Right Boundary | `j==n` |
| Shifted Main Diagonal | `i==j+k` or `i==j-k` |
| Shifted Secondary Diagonal | `i+j==n+1+k` or `i+j==n+1-k` |
