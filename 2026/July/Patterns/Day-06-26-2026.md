# 🧠 The Golden Rule

For every matrix position `(i, j)` ask:

> **Should I print `*` or a space?**

General Structure

```java
for(i = 1; i <= n; i++) {
    for(j = 1; j <= n; j++) {

        if(condition) {
            System.out.print("*");
        } else {
            System.out.print(" ");
        }

    }
    System.out.println();
}
```

Only the **condition** changes.

# 📚 Matrix Pattern Conditions

## 1. Boundary Pattern

Condition

```java
i == 1 || i == n || j == 1 || j == n
```

---

## 2. Main Diagonal

Condition

```java
i == j
```

---

## 3. Secondary Diagonal

Condition

```java
i + j == n + 1
```

---

## 4. X Pattern

Condition

```java
i == j || i + j == n + 1
```

---

## 5. Boundary + X

Condition

```java
i == 1 ||
i == n ||
j == 1 ||
j == n ||
i == j ||
i + j == n + 1
```

---

## 6. Left Boundary + Main Diagonal + Bottom Boundary

Condition

```java
i == n ||
j == 1 ||
i == j
```

---

## 7. Top Boundary + Left Boundary + Secondary Diagonal

Condition

```java
i == 1 ||
j == 1 ||
i + j == n + 1
```

---

## 8. Bottom Boundary + Right Boundary + Secondary Diagonal

Condition

```java
i == n ||
j == n ||
i + j == n + 1
```

---

## 9. Top & Bottom Boundary + X

Condition

```java
i == 1 ||
i == n ||
i == j ||
i + j == n + 1
```

---

## 10. Left & Right Boundary + X

Condition

```java
j == 1 ||
j == n ||
i == j ||
i + j == n + 1
```

---

## 11. Shifted Diagonal (Diamond Outline)

Condition

```java
i + j == n + 1 - 4 ||
i + j == n + 1 + 4 ||
i == j - 4 ||
i == j + 4
```

# 📋 Matrix Pattern Formula Sheet

| Pattern | Condition |
|----------|-----------|
| Boundary | `i==1 || i==n || j==1 || j==n` |
| Main Diagonal | `i==j` |
| Secondary Diagonal | `i+j==n+1` |
| X Pattern | `i==j || i+j==n+1` |
| Boundary + X | Boundary + Both Diagonals |
| Top Boundary | `i==1` |
| Bottom Boundary | `i==n` |
| Left Boundary | `j==1` |
| Right Boundary | `j==n` |
| Shifted Main Diagonal | `i==j+k` or `i==j-k` |
| Shifted Secondary Diagonal | `i+j==n+1+k` or `i+j==n+1-k` |
