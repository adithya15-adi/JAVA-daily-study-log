
---

### 3. Count Subarrays with Target Sum

Given:

```text
Target = 30
```

Counted all subarrays whose sum is equal to the target value.

---

## 📝 Algorithm

1. Select the starting index (`i`).
2. Select the ending index (`j`).
3. Traverse from `i` to `j`.
4. Calculate the sum.
5. If the sum equals the target, increment the count.

---

## 📊 Time Complexity

| Operation | Complexity |
|-----------|-----------:|
| Print All Subarrays | **O(n³)** |
| Calculate Sum of Every Subarray | **O(n³)** |
| Count Target Sum Subarrays | **O(n³)** |

---

## 💡 Key Learnings

- A subarray consists of contiguous elements.
- Three nested loops are required in the brute force approach:
  - First loop → Starting index
  - Second loop → Ending index
  - Third loop → Traverse and calculate the sum
- Brute force checks every possible subarray.
- Although simple, the approach is inefficient for large arrays because of its cubic time complexity.
