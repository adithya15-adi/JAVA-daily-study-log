## 💻 Programs Implemented

### 1. Print All Possible Pairs

```text
(1,1)
(1,2)
...
(5,5)
```

---

### 2. Print Unique Pairs (`i < j`)

Example:

```text
10 20
10 30
10 40
...
```

---

### 3. Print Sum of Every Pair

Example:

```text
10 + 20 = 30
20 + 40 = 60
...
```

---

### 4. Pair Sum Problem

Find all pairs whose sum equals a given target.

Example:

```text
Target = 60

Output

10,50
20,40
```

---

### 5. Triplet Sum Problem

Find all triplets whose sum equals a target value.

Example:

```text
Target = 60

Output

10,20,30
```

---

### 6. Pair Difference Problem

Find all pairs where:

```text
|arr[i] - arr[j]| = k
```

Example:

```text
Array = [1,5,3,4,2]
k = 2

Output

1,3
5,3
4,2
```

---

## 📚 Key Concepts

- Brute Force solves problems by checking every possible combination.
- Nested loops are commonly used for pair and triplet problems.
- Using `i < j` avoids duplicate pairs.
- `Math.abs()` helps compare absolute differences.
- Brute Force is simple to understand but may not be efficient for large inputs.

---

## 📊 Time Complexity

| Problem | Complexity |
|----------|-----------:|
| Print All Pairs | **O(n²)** |
| Unique Pairs | **O(n²)** |
| Pair Sum | **O(n²)** |
| Pair Difference | **O(n²)** |
| Triplet Sum | **O(n³)** |
