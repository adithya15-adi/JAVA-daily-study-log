## 📋 Syntax Learned

### 2D List

```python
a = [
    [1,2,3],
    [4,5,6],
    [7,8,9]
]
```

### Traverse using For-Each

```python
for row in a:
    for value in row:
        print(value)
```

### Traverse using Indexes

```python
for i in range(len(a)):
    for j in range(len(a[i])):
        print(a[i][j], end=" ")
    print()
```

### Sum of Array

```python
total = 0

for num in a:
    total += num
```

### Mini-Max Sum

```python
total = sum(a)

minimum = total - max(a)
maximum = total - min(a)
```
