## 📋 Syntax Learned

### 2D List

```python
a = [
    [1,2,3],
    [4,5,6],
    [7,8,9]
]
```

### Traverse using For-Each Loop

```python
for row in a:
    for value in row:
        print(value)
```

### Traverse using Indexes

```python
for i in range(len(a)):
    for j in range(len(a[i])):
        print(a[i][j], end=" ")
    print()
```

### Sum of Array

```python
total = sum(a)
```

### Mini-Max Sum

```python
total = sum(a)

minimum = total - max(a)
maximum = total - min(a)

print(minimum, maximum)
```

### Diagonal Difference

```python
primary = 0
secondary = 0

for i in range(len(a)):
    primary += a[i][i]
    secondary += a[i][len(a)-1-i]

print(abs(primary - secondary))
```

## 💡 Key Learnings

- A 2D list is a list of lists.
- Nested loops are used to traverse matrices.
- `len()` helps determine rows and columns.
- `sum()`, `min()`, and `max()` simplify array calculations.
- Primary diagonal elements satisfy `i == j`.
- Secondary diagonal elements satisfy `i + j == n - 1`.
- Diagonal Difference is the absolute difference between the sums of the two diagonals.
