## 🧠 Key Learnings

- Arrays have a fixed size, whereas ArrayLists are dynamic.
- ArrayLists can grow and shrink automatically.
- ArrayLists store objects, so primitive types use wrapper classes like `Integer`.
- The `Collections` class provides useful utility methods for searching and sorting.
- Generic types improve type safety and readability.

---

## ⚖️ Array vs ArrayList

| Array | ArrayList |
|------|-----------|
| Fixed Size | Dynamic Size |
| Stores primitives and objects | Stores objects only |
| Faster | Slightly slower |
| Length using `length` | Size using `size()` |
| Less flexible | More flexible |
