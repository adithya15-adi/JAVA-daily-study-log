## 📋 Syntax Learned

### Array Declaration

```java
int[] arr = new int[5];
```

### Array Initialization

```java
int[] arr = {10, 20, 30, 40, 50};
```

### Array Traversal

```java
for(int i = 0; i < arr.length; i++) {
    System.out.println(arr[i]);
}
```

### Prefix Sum Array

```java
int[] prefix = new int[arr.length];

prefix[0] = arr[0];

for(int i = 1; i < arr.length; i++) {
    prefix[i] = prefix[i - 1] + arr[i];
}
```
